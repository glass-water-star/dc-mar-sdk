[1] /api/v2.2/autocomplete/{address}
────────────────────────────────────────────────────────────────────────────

Status: ❌ MISMATCH (but HANDLED)

Swagger Specification:
  - Returns: array[string]
  - Example: ["1600 PENNSYLVANIA AVENUE NW", "1600 PENNSYLVANIA AVENUE SE"]

Actual API Response:
  - Returns: object with Result/Success/Message
  - Example: {
      "Result": ["1600 PENNSYLVANIA AVENUE NW", "1600 PENNSYLVANIA AVENUE SE"],
      "Success": true,
      "Message": null
    }

Analysis:
  This is a BREAKING DIFFERENCE between Swagger documentation and implementation.
  The API wraps results in an object with status information, but the spec
  documents it as returning a direct array.

Current Workaround (in src/dc_mar_sdk/client/mar.py):
  ✓ Client automatically extracts "Result" field
  ✓ No breaking changes to users
  ✓ Gracefully handles both formats

Impact: NONE (transparent to users)
